Case 02 · Technical depth

Healthcare AI Co-Pilot

Stack: Multimodal ML — imaging, tabular, NLP Role: Solo build See it live →

The problem

Clinical review often means pulling together three separate kinds of evidence by hand — imaging, structured risk factors, and written notes — before a decision gets made. I wanted to see if one panel could bring all three into a single review flow.

What I did

Built a multimodal decision-support panel across three tabs: Imaging (CXR) — chest X-ray pneumonia screening, either upload a real grayscale X-ray or generate a synthetic demo sample; Cardiac Risk (Tabular/ANN) — structured patient risk factors through a trained network; and Patient Notes (Text) — clinical notes as the third modality. The interface is explicit that demo runs are on synthetic data, and that a real vision or OCR API is needed before any production use — I didn't want the UI implying clinical validity it doesn't have.

Real screen recording — imaging tab, X-ray upload/synthetic-generation flow.

Why this case, not AI Road Guard

I originally planned to feature AI Road Guard (live road-crack detection on YOLOv8n) here, but I didn't have a usable live capture ready when it came time to gather proof images. Rather than fake a screenshot or ship a placeholder, I swapped it for this case — Co-Pilot's three-modality depth proves the same "real, technically deep" claim at least as well, and I had an actual recording of it working.

How it's built, no mystery code

Each tab is an independent input path feeding its own model type: the imaging tab expects a grayscale image (PNG/JPG) and runs it through a screening model or generates a synthetic demo sample if none is uploaded; the tabular tab runs structured fields through a small trained network (ANN) for cardiac risk; the notes tab takes free text for qualitative review. The three don't currently fuse into one combined score — they sit side by side in one review interface, which is an honest description of what the demo does today, not a claim of a unified multimodal model.

The honest gap

Deployed on Streamlit Community Cloud. Demo still runs on synthetic data, and the disclaimer in the UI is real: it's built to demonstrate the multimodal review flow, with a note pointing to plugging in real Kaggle/UCI datasets before any production use.
