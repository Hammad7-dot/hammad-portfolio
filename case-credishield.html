CrediShield — AI Co-Pilot for Bank Loan Underwriting

Stack: Multimodal ML pipeline, dashboard UI Role: Solo build See it live →

The problem

Bank loan managers were manually reviewing documents and calculating risk by hand for every application — slow, repetitive work that didn't need a human doing it line by line.

What I did

Built CrediShield to take that off their plate — it analyzes the applicant's data across three modalities in one panel: tabular financial data (income, loan amount, term, credit history), unstructured text (the applicant's letter of intent), and image data (KYC/collateral documents). It generates risk charts and produces a PDF summary automatically.

I'd originally included an image upload/KYC verification section, but it wasn't working reliably, so I cut it rather than ship something broken, and refactored the rest into a clean multi-file architecture.

Real screen recording — the underwriting panel: tabular financial data, applicant letter of intent, and KYC/collateral image upload.

How it's built, no mystery code

The panel is a Streamlit frontend collecting three input types per applicant. Tabular fields (income, loan amount, term, credit history, education, self-employed status) feed a structured risk model. The free-text letter of intent is a separate modality passed through for qualitative context. The image upload path (KYC/collateral) is present in the UI but explicitly disabled — the demo copy says "please upload an image asset to fulfill the multimodal pipeline validation" rather than pretending it's a production identity-verification pipeline, because it isn't one yet.

The honest gap

Deployed on Streamlit Community Cloud. The risk models are trained on a small, dated public loan-approval dataset (491 applications) — the app says so directly on the panel ("not your institution's real underwriting history, treat scores as illustrative"). The image/KYC upload is still simulated, not a real verification pipeline.

What came of it

A loan manager can now run an application through the app and get a risk score, charts, and a summary PDF back — automatically, instead of doing it by hand.
